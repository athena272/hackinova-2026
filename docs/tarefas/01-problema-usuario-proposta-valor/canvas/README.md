# Canvas — Tarefa 01

Materiais visuais da InnovaPair para slides e mentoria.

## Como usar

1. **PNG** — cole direto no PowerPoint / Google Slides.
2. **HTML** — abra no navegador para ajustar texto e exportar (Ctrl+P → PDF).

```bash
# Windows (a partir da raiz do repo)
start docs/tarefas/01-problema-usuario-proposta-valor/canvas/empatia-e-valor.html
```

| Arquivo | Conteúdo |
| --- | --- |
| `empatia-e-valor.html` | Mapa de Empatia + Canvas de valor (2 seções) |
| `mapa-empatia.png` | Mapa de Empatia (Ana, 42) |
| `canvas-valor.png` | Problema → Evidência → Valor → Solução |
